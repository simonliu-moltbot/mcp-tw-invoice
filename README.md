# Taiwan Invoice Lottery MCP Server (台灣統一發票對獎助手)

這是一個 Model Context Protocol (MCP) 伺服器，專為查詢與核對 **台灣統一發票 (Taiwan Uniform Invoice)** 中獎號碼而設計。

## 🌟 特色 (Features)

*   **Official Data Source**: 直接解析財政部官方 XML RSS Feed，資料準確且穩定。
*   **Smart Check**: 支援輸入 **末三碼** 或 **完整八碼**，自動判斷所有獎項 (包含六獎、五獎...至頭獎)。
*   **Standard MCP**: 使用官方 `mcp` Python SDK 實作，相容性高 (無 stdout 雜訊)，完美支援 **Dive**、**Claude Desktop** 等客戶端。

## 🚀 快速開始 (Quick Start)

### 1. 安裝依賴 (Install)
```bash
# 建立虛擬環境 (建議使用 Python 3.10+)
python3 -m venv .venv
source .venv/bin/activate

# 安裝依賴
pip install -e .
```

### 2. 在 Dive (MCP Host) 中使用

無需額外腳本，直接在 Dive 的 MCP Server 設定中加入：

*   **Type**: `stdio`
*   **Command**: `(您的專案路徑)/.venv/bin/python`
    *   例如: `/Users/username/projects/mcp-tw-invoice/.venv/bin/python`
*   **Args**: `(您的專案路徑)/src/server.py`
    *   例如: `/Users/username/projects/mcp-tw-invoice/src/server.py`

### 3. 在 Claude Desktop 中使用

編輯設定檔 `~/Library/Application Support/Claude/claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "tw-invoice": {
      "command": "/absolute/path/to/projects/mcp-tw-invoice/.venv/bin/python",
      "args": [
        "/absolute/path/to/projects/mcp-tw-invoice/src/server.py"
      ]
    }
  }
}
```

## 🛠 開發與測試

手動執行 Server (stdio 模式)：
```bash
python src/server.py
```
*Server 啟動後會等待 stdin 輸入 JSON-RPC 指令。*
