# Taiwan Invoice Lottery MCP Server (台灣統一發票對獎助手)

這是一個基於 `fastmcp` 的 Model Context Protocol (MCP) 伺服器，專為查詢與核對 **台灣統一發票 (Taiwan Uniform Invoice)** 中獎號碼而設計。

## 🌟 特色 (Features)

*   **Real Data**: 直接從財政部稅務入口網抓取最新開獎號碼 (Web Scraping)。
*   **Auto Check**: 輸入發票末三碼或全碼，自動判斷是否中獎及獎項。
*   **MCP Ready**: 支援 Standard MCP Protocol (Stdio/SSE)。

## 🚀 快速開始 (Quick Start)

### 1. 安裝依賴 (Install)
```bash
pip install -e .
```

### 2. 執行伺服器 (Run)
```bash
# 開發模式
fastmcp dev src/server.py
```

### 3. 使用 Docker
```bash
make up
```

## 🛠 MCP 設定 (Configuration)

若要將此服務加入 Claude Desktop App，請編輯 `~/Library/Application Support/Claude/claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "tw-invoice": {
      "command": "/absolute/path/to/venv/bin/python",
      "args": [
        "/absolute/path/to/projects/mcp-tw-invoice/src/server.py"
      ]
    }
  }
}
```
*請將 `/absolute/path/to/...` 替換為您實際的絕對路徑。*
